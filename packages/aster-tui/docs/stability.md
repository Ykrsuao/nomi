## 2026-11-10：双 Esc 清空草稿与对话回退

空闲时 600 毫秒内连续按两次 Esc：有草稿时整份清空，Ctrl+Z / Ctrl+U 可撤销；输入框为空时打开检查点列表，默认选中最新消息，也可以输入筛选。Enter 从选中消息之前创建新会话，把原始文字放回输入框，不自动发送。原会话可在 `/sessions` 中重新打开，工作文件保持当前内容。`/rewind` 提供同样入口。

单次 Esc 仍优先关闭面板和建议、撤回准备期间的待发消息或取消任务。这些操作不会成为双 Esc 的第一次按键；其他按键、粘贴、鼠标、超时及会话切换也会重置计时，按键重复和释放不会触发。存在待发队列时先处理队列。回退或加载失败保留原对话；加载期间另写草稿会保留新草稿，将选中的旧消息放入暂停队列。

后端在接收新消息前保存检查点，包含可序列化的代理状态、不可变事件版本及当时的活动事件顺序。回退后下一次模型输入不包含被舍弃的后续消息，变量、上下文和待办同步恢复；两个会话都可以在重启后打开。事件版本按内容去重，之后的压缩和删除不会改变历史检查点。旧消息没有检查点时不会列为可回退项；状态不可序列化时仍接收普通消息，但不提供不完整的回退点。回退不会恢复后台进程或已经执行的文件操作。

## 2026-11-10：后台准备会话与撤回待发送消息

本轮将会话准备提前到界面打开后，准备期间保留欢迎页和可编辑输入框；只有已经提交但尚未发送的消息等待时才显示准备提示。Enter 将消息放入队列，准备完成后按顺序发送。Esc 把队首待发送消息退回空输入框，并暂停剩余队列；已有另一份草稿时保留两份内容并打开暂停队列。后台准备继续，撤回的消息不会因准备完成而被发送。

输入历史和消息记录在实际发送 prompt 时建立。`--resume`、`--continue` 保持恢复原会话的语义，`/new` 关闭旧会话后提前准备下一会话。未使用的预备会话在正常关闭时清理。异步剪贴板使用逻辑会话代号区分真正的会话切换，同一会话准备完成取得 ID 不会丢弃正在读取的粘贴内容。
